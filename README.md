# Lan to Bluetooth WoL for the PS3
Receive WoL packets using the RP PICO 2040 (or newer) WiFi and send them as Bluetooth packets emulating a real DS3 controller
<br>
To use configure platformio.ino with your wireless credentials and the data obtained from your PS3 controller using SixaxisPairTool (for PS3 bt board) + any Bluetooth app that shows MAC addresses (for the controller's)
